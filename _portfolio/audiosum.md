**Audiosum** is my B.Sc. thesis project (Aug 2024 -- Feb 2025, University of Ibadan): a novel multimodal video summarization framework.

* Visual features from pre-trained CNNs (**ResNet50, VGG16**); custom **audio feature extractor** to improve summary representativeness.
* Feature fusion via a fully-connected layer combining audio + visual embeddings.
* **LSTM** network for temporal dependency capture to select concise, representative segments.
