B.Sc. honors dissertation (First Class Honours). Developed Audiosum, a multimodal video summarization framework using pre-trained CNNs (ResNet50, VGG16) for visual features and a custom audio feature extractor, with FC-layer audio-visual fusion and an LSTM for temporal modeling.
